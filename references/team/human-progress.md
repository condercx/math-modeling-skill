# 人类团队进度与下一步建议

用户问“做到哪一步”“下一步是什么”“现在谁该干什么”时，按当前文件和真实产物回答。项目 `AGENTS.md` 与实际任务说明优先；不要求维护 `STATUS/TASKS/handoff`，这些文件如不存在也不视为缺失流程。

读取：
- `AGENTS.md`、`README.md`、`problem/dependency.md`
- 存在的任务说明、`STATUS/TASKS/Handoff` 和 review
- `models/`、`src/`、`experiments/`、`results/` 的真实当前状态

输出：
1. 已知完成项及其真实证据；
2. q1..qN 当前进展和未知项；
3. 实际阻塞及依赖；
4. 最有价值的下一步，可按需要列并行任务；
5. 可运行命令、结果路径和限制。

只有真实文件、运行日志、结果和可复核产物能证明完成；口头讨论或 Agent 自述不算。
