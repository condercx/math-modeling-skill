# 项目级模型路由（团队模式）

本参考只规定不随型号变化的边界。当前使用哪个主 Agent、子代理、reviewer 和 effort，先读项目 `AGENTS.md`；若项目存在专门的模型路由文件，以该文件为唯一当前路由入口。不要从本 Skill 的旧版本、历史回执或模型名称推断未来默认值。

- 主 Agent 按任务复杂度、风险、时效和当前环境能力自主选型；用户明确指定的受支持路由优先。
- 子代理任务必须有具体问题、可读输入、明确输出、写域和停止条件。探索输出是候选，不得独自冻结模型、公式、阈值、目标函数、约束或接口。
- 独立质检由未参与被审产物编写或修正的 Agent 只读执行。模型不同不自动证明独立；回执须记录固定输入、受审范围、实际 model/effort 和证据。
- 没有合格独立 reviewer 能力时按原 Skill 标记受限或 `BLOCKED`，不得用作者自检冒充 PASS。
- 历史 AI 账本、旧 review 和完成任务中的实际模型保持原事实，不因现行路由批量替换。
