# Sol / Luna 路由（2026 华为杯团队模式）

Sol 是唯一默认主 Agent，贯穿题意、模型、实现、实验、验证和论文证据链；人类保留关键取舍与最终决定。

Luna 可用时优先用于能与主线并行的高 token 探索、宽搜、文献/附件整理、候选方案比较和重复核查，子代理 `effort=max`（若环境允许）。提供具体问题、可读输入、明确输出、允许写域和停止条件；Sol 同时推进不依赖其结果的工作。Luna 不独自决定模型/公式/阈值/目标函数/约束/接口，输出的来源和结论须复核。

原 Skill 的独立质检门禁依旧由未参与写入的 Agent 只读审核。Luna 可承担质检，但不能先写同一产物再审核。子代理不可用时 Sol 完成探索，独立门禁不可用则按原 Skill 标记受限/阻塞，不得假称通过。

DSH/Flash/Astra/AnySearch 只作为历史工作流记录，不是默认运行前置条件。
