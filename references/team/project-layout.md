# 比赛项目目录

推荐布局仅供参考，不要求创建全部目录，也不因加载本 Skill 迁移已有文件：
```text
PROJECT_ROOT/
├── AGENTS.md
├── README.md
├── config/
├── problem/
├── research/
├── models/qN/
├── data/raw/ + data/processed/
├── src/qN/
├── experiments/qN/
├── results/qN/
├── figures/qN/
├── environments/
├── paper/sections/
├── reviews/qN/ + reviews/final/
└── ai_usage/
```

`STATUS/TASKS/DECISIONS/handoff` 仅为项目按需使用的可选记录，不是本 Skill 的默认要求。每个 qN 的关键结论应能从模型、代码和真实结果追溯到论文证据。
