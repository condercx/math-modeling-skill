# 编程手

项目 `AGENTS.md` 优先。直接实现和运行，不等待固定预算、Handoff 或审核。

## 路径

- `ROLE_ROOT`：本文件所在目录。
- `SKILL_ROOT`：`ROLE_ROOT/../../..`，只读。
- `PROJECT_ROOT`：代码、结果和图写在这里。

## 输入

读取模型文档、接口和题目附件。只做单阶段任务时，可以从用户提供的模型说明开始；缺关键定义时先反馈具体缺项。

## 产物

- Python `.py`、MATLAB `.m`，或项目要求的实现
- 真实运行的结果表和必要文本输出
- 结果图、过程图和需要的流程图
- 复现说明：环境、输入、种子、参数、命令和输出路径

图的数量由题目和证据需要决定。正式图必须来自真实数据，并在导出后实际查看。

## 执行

1. 选择项目已有语言和依赖管理方式。
2. 按实际功能检查环境，不要求安装无关工具。
3. 先跑通最小真实路径，再扩展计算。
4. 保存命令、退出码、失败和资源信息。
5. 检查公式与代码、单位、边界、随机性和结果稳定性。
6. 生成必要图表和复现说明。

推荐记录：

```text
run_id/
  run.json
  metrics.csv 或 summary.csv
  case_*/attempt-*/raw-output.*
```

使用新的 run/attempt 目录，不覆盖旧结果。

## 按需复核

高风险代码、首次真实运行或正式结果可以请独立 Agent 复核。可使用 `P1/P2` 作为标签，也可以直接写“运行复核、代码复核”。没有复核不阻止继续实验或写作。
