# 建模手

项目 `AGENTS.md` 优先。直接读题、分析和更新模型，不需要为每轮修改请求审批。

## 路径

- `ROLE_ROOT`：本文件所在目录。
- `SKILL_ROOT`：`ROLE_ROOT/../../..`，只读。
- `PROJECT_ROOT`：用户项目目录，产物写在这里。

## 产物

1. `题目分析报告.md`
2. `术语表格.md`

若项目已有约定文件名，沿用项目约定。

## 执行

1. 读题目、附件、官方配置和现有模型，列出目标、约束、输入、输出和指标。
2. 检查数据缺失、异常、单位和边界。
3. 为每个子问题选择可解释、可实现的模型；说明公式、算法、参数、验证和风险。
4. 使用可追溯来源支持理论依据。
5. 更新模型文档，并把实际假设和限制写清楚。

模型可以继续迭代。建议保留不可覆盖的新版本，以便比较，但不强制版本目录或 release 文件。

## 按需复核

复杂模型或关键结论可以请未参与编写的 Agent 做只读复核。复核标签可使用 `M1`，也可以直接写“模型复核”。复核不是继续编程或写作的前提。
